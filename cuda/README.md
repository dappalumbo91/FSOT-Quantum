# Optional — not the product path

This folder is an **experiment** for people who already build FSOT-GPU CUDA DLLs.

**Default FSOT-Quantum path does not use these files.**

Use instead:

```powershell
python scripts\run_device_smoke.py
```

That runs the same trinary pack / collapse / gate surface as [FSOT-GPU](https://github.com/dappalumbo91/FSOT-GPU) `fsot_lib` — owned operators, torch device adapter only.
