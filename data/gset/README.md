# Official Gset graphs

Source (Ye / Stanford): `https://web.stanford.edu/~yyye/yyye/Gset/`

`G1.txt` is fetched by `fsot_quantum.gset_official` (default allow fetch).
Format: first line `n m`, then `i j w` (1-based).

This is **not** a claim that we match published champion cuts for all G1–G54.
The fold residual is cut / n_edges ≥ 1/φ unless noted.
