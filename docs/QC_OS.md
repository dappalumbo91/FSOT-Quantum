# FSOT-QC-OS — metal subset, not the Python host

Reality OS can host this later. **We do not need to hijack it now.**  
This image is already a tiny OS: Multiboot, no Linux, no Windows, QEMU-loadable.

Python (`python -m fsot_quantum`) is the **living wrap**: known **44/44**, Gset family, heights17, organ, five-prover stamp.  
QC-OS is the **integer subset** of those hired jobs that fit a freestanding kernel. It is not behind the host. It is not the full host.

## What it is

- Own kernel (`zig/src/os.zig` + `main_kernel.zig`)
- Serial is the console
- Services: core selftest + hired QC/QM job table
- Version **0.3.0** — **13/13** integer jobs: dj, bv, search, period, periodmid, factor, ising, add2, add3, mulmod, chsh, domain, foldcost
- Serial shell: `a` all · `c` core · `j` jobs · `h` help
- Apache-2.0 · pin D1D38A

| Surface | What it runs | What it does not run |
|---------|--------------|----------------------|
| Python host | living wrap, 44/44 known, family, heights17, organ | — |
| QC-OS QEMU | 13 integer hired jobs on metal | Gset n=800, RSA-shaped 119-bit, pin chemistry 68/68 |

## Run anywhere QEMU exists

```powershell
.\run_qemu.ps1
```

Expect:

```text
FSOT-QC-OS v0.3.0
standalone quantum job OS - no host OS, no fridge
pin D1D38A Apache-2.0 trinary -1/0/+1
SHELL a=all c=core j=jobs h=help
...
JOBS 13/13
FSOT_QUANTUM_JOBS PASS
FSOT-QC-OS READY
```

Interactive: `.\run_qemu_stdio.ps1`
